# AI & Data Analysis Projects

Проекты по анализу данных и машинному обучению на языке Python.

## 📌 LabWork 1: Анализ и визуализация цен на золото
Загрузка, предобработка и исследовательский анализ данных (EDA) датасета с ценами на золото (Gold Price Prediction Dataset).

### 🛠 Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn
* **Среда разработки:** Jupyter Notebook / VS Code

### 📂 Структура проекта
* `01_data_loading.ipynb` — ноутбук с загрузкой данных и первичным анализом.
* `data/` — папка с исходными датасетами (.csv).
