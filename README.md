✅ Выполнено
Lab 1 — EDA и визуализация
Данные: цены на золото (1718 × 81).

Загрузка, разведочный анализ (info, describe, shape, loc/iloc).

Feature engineering: Year, Price_Range.

6 типов визуализаций: гистограммы, boxplot по годам, scatter, линейные графики со скользящим средним, тепловая карта корреляций.

Ключевой вывод: цены Open/High/Low/Close сильно коррелируют (>0.99) — мультиколлинеарность; объём торгов с ценой связан слабо.

Lab 2 — Предобработка и дисбаланс
Данные: золото (1718), Starbucks (8036), зарплаты (3755).

Train/Val/Test split (60/20/20).

Обработка пропусков тремя методами: dropna, fillna(0), fillna(mean).

Удаление выбросов в зарплатах по 99-му процентилю (отсечено 37 записей).

Балансировка классов: SMOTE и RandomUnderSampler.

Lab 3 — Feature Engineering + ML
Данные: медицинские данные пациентов (70 000 строк → 68 619 после очистки).

Очистка от физиологически невозможных значений (давление, рост, вес).

Ручные признаки: age_years, bmi.

Дискретизация возраста + One-Hot Encoding (drop="first").

Featuretools (Deep Feature Synthesis): 25 автоматически сгенерированных признаков.

Модель: Random Forest (100 деревьев).

Результаты:

Метрика	Значение
Accuracy (Val)	71.20 %
Accuracy (Test)	71.54 %
Топ-признаки	ap_hi (0.43), ap_lo (0.34), age (0.24), cholesterol (0.23)
