# AI & Data Analysis Projects

Проекты по анализу данных и машинному обучению на языке Python. Включает исследовательский анализ (EDA), предобработку данных и работу с дисбалансом классов.

## 📌 Проект 1: Анализ финансовых и HR-данных
Загрузка, предобработка и анализ данных (на примере цен на золото, акций и зарплат в Data Science).

### 🛠 Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Imbalanced-learn
* **Инструменты:** Poetry,Ruff, Jupyter Notebook / VS Code

### 📂 Структура проекта
* `01_data_loading.ipynb` — ноутбук с загрузкой данных, визуализацией и первичным анализом (EDA).
* `02_data_preprocessing.ipynb` — анализ бизнес-целей, разделение данных (Train/Val/Test), обработка пропусков и устранение дисбаланса классов (SMOTE, Undersampling).
* `data/` — папка с исходными датасетами (.csv).
* `pyproject.toml` — конфигурация зависимостей проекта.
